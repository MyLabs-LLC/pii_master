HARBOUR AREA TRANSIT AUTHORITY
PRIVACY STANDARD 7 — SCHEDULE OF ACCESS AUTHORISATIONS
Effective September 2004. Issued under the authority of the Records Custodian.

The following schedule states, for each holding, the fields carried and the roles authorised. No other role has access. Authorisation to a holding does not confer authorisation to extracts of it held elsewhere.

* PERSONNEL MASTER FILE
  Fields: Employee Number / Surname / Given Names / Grade / Division / Date of Engagement / Date of Separation / Next of Kin Name / Next of Kin Telephone
  → Authorised: Personnel Officer; Deputy Personnel Officer; Records Custodian
  → Read-only extract: Establishment Planning Section, Employee Number and Grade only

* PAYROLL AND DEDUCTIONS FILE
  Fields: Employee Number / Pay Band / Bank Sort Reference / Account Reference / Tax Reference / Court Order Reference / Deduction Code
  → Authorised: Payroll Supervisor; Payroll Clerks on the standing list
  → No extract of any kind is permitted

* OCCUPATIONAL HEALTH FILE
  Fields: Employee Number / Referral Reason / Practitioner Reference / Fitness Determination / Restriction Code / Review Date
  → Authorised: Occupational Health Officer
  → Line managers receive Fitness Determination and Restriction Code only, by written notice

* DRIVER LICENSING AND COMPETENCE FILE
  Fields: Employee Number / Licence Class / Licence Number / Endorsement Code / Assessment Outcome / Assessor / Expiry Date
  → Authorised: Licensing Registrar; Depot Managers, for their own depot establishment only

* CONCESSIONARY TRAVEL REGISTER
  Fields: Member Number / Surname / Given Names / Entitlement Class / Date of Birth / Card Serial / Correspondence Address / Photograph Reference
  → Authorised: Concessions Section; Revenue Protection Inspectors, by Member Number lookup only

* COMPLAINTS AND CLAIMS REGISTER
  Fields: Case Reference / Complainant Name / Correspondence Address / Contact Telephone / Service Line / Vehicle Number / Disposition Code
  → Authorised: Customer Services Manager; case handlers assigned to the case

* SURVEILLANCE IMAGE STORE
  Fields: Incident Reference / Camera Identifier / Location Code / Time Reference / Subject Description / Retrieving Officer
  → Authorised: Security Controller
  → Release to any person outside the Authority: written instruction of the Records Custodian, recorded in the Disclosure Log

STANDING CONDITIONS
* Every retrieval is logged against Requesting Role, Holding, Purpose Code and Date.
* The Disclosure Log is inspected quarterly by the Records Custodian and annually by Internal Audit.
* Authorisations lapse on transfer or separation and are not carried to a new post.
* Removal of any holding from Authority premises requires prior written approval and a signed movement docket.
