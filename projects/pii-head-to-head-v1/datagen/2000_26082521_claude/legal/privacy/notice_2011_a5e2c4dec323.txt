RECORDS HANDLING STANDARD — SUPPLEMENT 2 OF 2016
DATA CATEGORY REGISTER AND HANDLING MATRIX

Section 1. Register maintenance

The Records Custodian maintains the Data Category Register. Each entry is recorded with the following fields, which must be completed in full before a category may be entered into production use:

  Field: Category Code
  Field: Category Description
  Field: Collection Point
  Field: System of Record
  Field: Authorised Role Set
  Field: Retention Trigger
  Field: Retention Period
  Field: Disposal Method
  Field: Register Owner
  Field: Last Review Date

Section 2. Categories in scope

  Code 100  Identity attributes
  Code 110  Government-issued identifiers
  Code 120  Contact attributes
  Code 200  Depository and disbursement account attributes
  Code 210  Source-of-funds evidence
  Code 300  Transaction and property attributes
  Code 310  Lender and loan attributes
  Code 400  Search and adverse-matter results
  Code 410  Notarised instrument images
  Code 500  Correspondence and call records

Section 3. Handling matrix

  Code 110 and Code 200 are designated Restricted. Restricted categories may not be transmitted by unencrypted electronic mail, may not be printed except to a supervised device, and may not be stored on portable media or on a workstation local drive.

  Codes 100, 120, 210, 300, 310, 400 and 410 are designated Confidential. Confidential categories may be transmitted through the secure delivery portal or by encrypted attachment only.

  Code 500 is designated Internal. Internal categories follow ordinary business handling but remain subject to the retention schedule.

Section 4. Retention triggers

  Restricted categories: trigger is confirmed disbursement. Period is 90 days in production, thereafter archive only.
  Confidential categories: trigger is policy issuance or file cancellation. Period is seven years, save that Code 210 is five years and Code 400 is three years.
  Internal categories: trigger is date of last entry. Period is three years.

Section 5. Disposal

  Eligibility is calculated monthly. Counsel endorses. Physical media are shredded to a particle size not exceeding the standard specified in the vendor agreement. Electronic records are cryptographically erased across primary, replica, and backup tiers. The Records Custodian signs the destruction log. No record is destroyed while a hold is in force.

Section 6. Review

  This Supplement and the Register are reviewed annually by the Compliance and Risk Committee, and on any material change to the escrow production system, the imaging repository, or applicable state escrow regulation.
