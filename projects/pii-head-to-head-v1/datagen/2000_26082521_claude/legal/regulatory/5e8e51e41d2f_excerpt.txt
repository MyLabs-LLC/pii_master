STATE REGISTER            VOL. 41, NO. 9            PERMANENT RULE ADOPTED
--------------------------------------------------------------------------------
AGENCY    : Board of Regents of the State University System
RULE NO.  : REG-2016-04
SUBJECT   : Safeguarding of Personal Information in Student Records
AUTHORITY : State Code Ann. tit. 34, ch. 12, sec. 12-109
POSTED    : Office of the University Registrar -- Compliance Binder, Tab 4
================================================================================

SEC.  1.  PURPOSE
          To prescribe minimum safeguards for personal information held
          in a student record system and to fix penalties for
          noncompliance.

SEC.  2.  DEFINITIONS
          As used in this rule --

          2.1  "Personal information" means a natural person's surname
               combined with one or more unencrypted elements listed in
               the table at Section 3.
          2.2  "Record system" means any file, database, index, or
               microform in which personal information is stored and
               retrieved by identifier.
          2.3  "Records Custodian" means the officer designated in
               writing by a unit head to answer for a record system.
          2.4  "Disclosure" means release, transfer, or provision of
               access, by any means, to a party other than the subject
               of the record.

SEC.  3.  IDENTIFIER CATEGORIES
          +------+---------------------------+------------------------+
          | CODE | CATEGORY                  | ELEMENT LABELS         |
          +------+---------------------------+------------------------+
          | A    | Government identifiers    | Social Security number |
          |      |                           | Taxpayer number        |
          |      |                           | Driver license number  |
          +------+---------------------------+------------------------+
          | B    | Institutional identifiers | Student number         |
          |      |                           | Network user name      |
          +------+---------------------------+------------------------+
          | C    | Financial identifiers     | Bank account number    |
          |      |                           | Payment card number    |
          +------+---------------------------+------------------------+
          | D    | Contact identifiers       | Residential address    |
          |      |                           | Telephone number       |
          |      |                           | Electronic mail address|
          +------+---------------------------+------------------------+
          | E    | Demographic identifiers   | Date of birth          |
          |      |                           | Place of birth         |
          +------+---------------------------+------------------------+
          | F    | Biometric identifiers     | Fingerprint template   |
          |      |                           | Facial geometry record |
          +------+---------------------------+------------------------+

SEC.  4.  OBLIGATIONS OF THE HOLDER
          4.1  No element in category A, C, or F shall be collected
               absent a written finding of necessity by the Registrar.
          4.2  A category A element shall not be used as a primary key,
               printed on an identification card, or placed in a message
               subject line.
          4.3  Each record system shall carry a custodian designation, a
               retention schedule, and an access log retained not less
               than three years.
          4.4  Disclosure to a third party requires a written agreement
               limiting redisclosure and requiring return or destruction
               at the close of the engagement.

SEC.  5.  NOTIFICATION
          Upon discovery of unauthorized acquisition of any element in
          category A, C, or F, the Records Custodian shall notify the
          Registrar the same business day, and the institution shall
          notify each affected person without unreasonable delay.

SEC.  6.  PENALTIES
          +-------+----------------------------+---------------------+
          | CLASS | CONDUCT                    | SANCTION            |
          +-------+----------------------------+---------------------+
          | I     | Negligent disclosure       | Reprimand; retrain  |
          | II    | Repeated negligence        | Access suspended    |
          | III   | Knowing disclosure         | $5,000 per record   |
          | IV    | Disclosure for gain        | Dismissal; referral |
          +-------+----------------------------+---------------------+

SEC.  7.  EFFECTIVE DATE
          This rule takes effect on the thirtieth day after publication.
