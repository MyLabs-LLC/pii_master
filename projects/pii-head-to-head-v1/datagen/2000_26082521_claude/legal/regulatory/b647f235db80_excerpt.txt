TITLE 21 -- TRADE, COMMERCE AND EMPLOYMENT
CHAPTER 4 -- PROTECTION OF PERSONAL IDENTIFYING INFORMATION HELD BY EMPLOYERS
Subchapter B -- Duties of Covered Holders            (excerpt; compiled 2016)

SECTION   | CATCHLINE             | PROVISION
----------+-----------------------+-----------------------------------------------------
21-4-101  | Definitions           | As used in this chapter, unless the context clearly
          |                       | requires otherwise, the several terms hereinafter
          |                       | set out shall be given the meanings herein
          |                       | ascribed.
          |                       |
          | (1) Covered holder    | Any person, firm, partnership, corporation, or
          |                       | unincorporated association that, in the ordinary
          |                       | course of its business, acquires, assembles,
          |                       | maintains, transmits, or otherwise comes into
          |                       | possession of a record containing personal
          |                       | identifying information concerning an applicant,
          |                       | employee, assigned worker, or former employee,
          |                       | whether such record be kept in paper, electronic,
          |                       | magnetic, optical, or any other form.
          |                       |
          | (2) Personal          | An individual's first name or first initial and
          |     identifying       | surname in combination with any one or more of
          |     information       | the data elements enumerated in the Identifier
          |                       | Schedule, where neither the name nor the data
          |                       | element is encrypted, redacted, or truncated.
          |                       |
          | (3) Disposal          | The discarding or abandonment of a record, or the
          |                       | sale, donation, or transfer of any medium upon
          |                       | which a record is stored, without regard to
          |                       | whether the holder intends that the record be
          |                       | read or reconstructed.
----------+-----------------------+-----------------------------------------------------
21-4-102  | Duty of care          | A covered holder shall implement and maintain
          |                       | reasonable administrative, technical, and
          |                       | physical safeguards, appropriate to the size and
          |                       | complexity of the holder's operations and to the
          |                       | nature and scope of its activities, to protect
          |                       | from unauthorized access, acquisition, use,
          |                       | modification, or disclosure any record containing
          |                       | personal identifying information. Such safeguards
          |                       | shall be reduced to writing and reviewed not less
          |                       | often than annually.
----------+-----------------------+-----------------------------------------------------
21-4-103  | Disposal of records   | A covered holder shall dispose of a record
          |                       | containing personal identifying information by
          |                       | shredding, erasing, or otherwise modifying such
          |                       | information so as to render it unreadable,
          |                       | indecipherable, and incapable of reconstruction
          |                       | by any means.
----------+-----------------------+-----------------------------------------------------
21-4-104  | Records custodian     | Each covered holder shall designate one officer
          |                       | or employee, to be styled the Records Custodian,
          |                       | charged with the receipt, indexing, storage, and
          |                       | lawful destruction of records containing personal
          |                       | identifying information.
----------+-----------------------+-----------------------------------------------------
21-4-105  | Access log            | The Records Custodian shall maintain a log of
          |                       | every retrieval of a record containing personal
          |                       | identifying information, in the form prescribed
          |                       | by rule of the Department.
----------+-----------------------+-----------------------------------------------------
21-4-106  | Civil penalty         | A violation of this subchapter shall constitute
          |                       | an unlawful practice and shall subject the holder
          |                       | to a civil penalty for each affected record,
          |                       | recoverable in an action brought by the Attorney
          |                       | General; provided, that a series of violations
          |                       | arising from a single act or omission shall be
          |                       | treated as one violation.
----------+-----------------------+-----------------------------------------------------

Compiled through Chapter 214, Regular Session.
