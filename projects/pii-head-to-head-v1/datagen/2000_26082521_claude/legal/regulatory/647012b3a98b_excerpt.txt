RULE 12-04-002  DEFINITIONS
Promulgated by the Department of Health pursuant to § 4-103 of the Public Health Code

+--------------------+----------------------------------------------------------+
| TERM               | DEFINITION                                               |
+--------------------+----------------------------------------------------------+
| Covered Record     | Any record, in written, electronic, magnetic, or other   |
|                    | form, that is created or maintained by a holder of       |
|                    | records and that contains one or more identifiers        |
|                    | enumerated in Section 2(c) of this rule.                 |
+--------------------+----------------------------------------------------------+
| Holder of Records  | Any hospital, clinic, billing office, collection agent,  |
|                    | or other person or entity that, in the ordinary course   |
|                    | of business, creates, receives, stores, transmits, or    |
|                    | disposes of a covered record.                            |
+--------------------+----------------------------------------------------------+
| Disclosure         | The release, transfer, provision of access to, or        |
|                    | divulging in any manner of a covered record, or of any   |
|                    | identifier contained therein, to any person other than   |
|                    | the individual who is the subject of the record.         |
+--------------------+----------------------------------------------------------+
| Identifier         | Any datum listed in the schedule set forth at Section    |
|                    | 2(c), whether standing alone or in combination with      |
|                    | any other datum, by which the identity of an individual  |
|                    | may reasonably be ascertained.                           |
+--------------------+----------------------------------------------------------+
