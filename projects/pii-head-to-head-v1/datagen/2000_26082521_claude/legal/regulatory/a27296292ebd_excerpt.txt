TITLE 12 — FINANCIAL INSTITUTIONS
CHAPTER 402 — PROTECTION OF PERSONAL INFORMATION IN RECORDS
SUBCHAPTER A — DEFINITIONS  (excerpt; effective 01 JAN 2021)

§ 402.101  DEFINITIONS.
As used in this chapter, unless the context requires otherwise:

+----------+---------------------------+----------------------------------------------+
| PARA.    | TERM                      | MEANING ASSIGNED                             |
+----------+---------------------------+----------------------------------------------+
| (a)(1)   | Covered Entity            | A state-chartered credit union, its service  |
|          |                           | organizations, and any agent holding records |
|          |                           | on its behalf.                               |
+----------+---------------------------+----------------------------------------------+
| (a)(2)   | Record                    | Any information inscribed on a tangible or   |
|          |                           | electronic medium from which a natural       |
|          |                           | person may be identified.                    |
+----------+---------------------------+----------------------------------------------+
| (a)(3)   | Direct Identifier         | A data element that identifies a natural     |
|          |                           | person without reference to other data.      |
+----------+---------------------------+----------------------------------------------+
| (a)(4)   | Derived Identifier        | A data element that identifies a natural     |
|          |                           | person only in combination with one or more  |
|          |                           | additional elements.                         |
+----------+---------------------------+----------------------------------------------+
| (a)(5)   | Records Custodian         | The officer designated under § 402.204 to    |
|          |                           | maintain the inventory of records.           |
+----------+---------------------------+----------------------------------------------+
| (a)(6)   | Disposal                  | Destruction, erasure, or modification such   |
|          |                           | that a record cannot practicably be read or  |
|          |                           | reconstructed.                               |
+----------+---------------------------+----------------------------------------------+
| (a)(7)   | Breach of Security        | Unauthorized acquisition of unencrypted      |
|          |                           | records that compromises confidentiality.    |
+----------+---------------------------+----------------------------------------------+

§ 402.102  CONSTRUCTION.
Terms not defined in this subchapter carry the meaning given in Title 12,
Chapter 100. Where a federal standard imposes a stricter duty, the stricter
duty controls. Nothing in this chapter creates a private right of action.
