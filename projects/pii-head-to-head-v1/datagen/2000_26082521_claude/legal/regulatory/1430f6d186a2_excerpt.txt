TITLE 19 -- COMMERCIAL TRANSPORT, WAREHOUSING AND FREIGHT FORWARDING
SUBCHAPTER C -- PROTECTION OF PERSONAL INFORMATION IN CARRIER RECORDS
Secs. 4-401 to 4-409                        Effective 01 JUL 1997; amd. 1999

+--------+----------------------+----------------------------------------------+
| SEC.   | HEADING              | PROVISION                                    |
+--------+----------------------+----------------------------------------------+
| 4-401  | Short Title          | This subchapter may be cited as the Carrier  |
|        |                      | Records Privacy Provisions.                  |
+--------+----------------------+----------------------------------------------+
| 4-402  | Definitions          | (a) "Holder of records": a motor carrier,    |
|        |                      | freight forwarder, broker, or warehouse      |
|        |                      | operator maintaining records that contain    |
|        |                      | personal identifiers of a natural person.    |
|        |                      | (b) "Personal identifier": any datum listed  |
|        |                      | in Schedule A, Categories I through IV.      |
|        |                      | (c) "Records Custodian": the officer named   |
|        |                      | under Sec. 4-403(a).                         |
|        |                      | (d) "Disclosure": transfer, display, sale,   |
|        |                      | lease, or release to any person other than   |
|        |                      | the subject or an employee of the holder     |
|        |                      | acting within the scope of duty.             |
+--------+----------------------+----------------------------------------------+
| 4-403  | Designation          | Each holder shall designate one Records      |
|        |                      | Custodian and file the designation on Form   |
|        |                      | PI-1, stating: Custodian Title; Office       |
|        |                      | Location Code; Facility Number; Date of      |
|        |                      | Designation.                                 |
+--------+----------------------+----------------------------------------------+
| 4-404  | Collection Limits    | No holder shall collect a Category III or    |
|        |                      | Category IV identifier except as required    |
|        |                      | for tariff, customs, or wage-reporting       |
|        |                      | purposes.                                    |
+--------+----------------------+----------------------------------------------+
| 4-405  | Storage and Access   | Records shall be held in locked cabinets or  |
|        |                      | in access-controlled systems. The access     |
|        |                      | log shall carry: User Identification Code;   |
|        |                      | Terminal Number; Time of Entry; File Class.  |
+--------+----------------------+----------------------------------------------+
| 4-406  | Disclosure           | Disclosure is barred absent written consent, |
|        |                      | subpoena, or a shipping necessity certified  |
|        |                      | by the Custodian on Form PI-2.               |
+--------+----------------------+----------------------------------------------+
| 4-407  | Retention            | Category I and II records: six years from    |
|        |                      | delivery. Category III and IV records: three |
|        |                      | years. Destruction by shredding or erasure,  |
|        |                      | logged on Form PI-4.                         |
+--------+----------------------+----------------------------------------------+
| 4-408  | Subject Access       | A subject may inspect and demand correction  |
|        |                      | of a record on written request. The holder   |
|        |                      | shall answer within thirty days.             |
+--------+----------------------+----------------------------------------------+
| 4-409  | Penalties            | Civil penalty not over $2,500 per record for |
|        |                      | negligent violation; not over $10,000 per    |
|        |                      | record for knowing violation; suspension of  |
|        |                      | operating authority for a pattern of         |
|        |                      | violations.                                  |
+--------+----------------------+----------------------------------------------+
