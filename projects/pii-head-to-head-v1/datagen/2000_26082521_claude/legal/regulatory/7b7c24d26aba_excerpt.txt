STATE CODE ANNOTATED, TITLE 34, CHAPTER 12
STUDENT RECORDS PRIVACY ACT -- EXCERPT
Retained: Office of the University Registrar        Effective: 07/01/2016
=========+======================+========================================
 SEC.    | CAPTION              | PROVISION
=========+======================+========================================
 12-101  | Short title          | This chapter may be cited as the
         |                      | Student Records Privacy Act.
---------+----------------------+----------------------------------------
 12-102  | Definitions          | (a) "Protected identifier" means any of
         |                      | the following elements when maintained
         |                      | in combination with an individual's
         |                      | name: Social Security number; state
         |                      | identification card number; financial
         |                      | account number; biometric record; date
         |                      | of birth; residential address;
         |                      | telephone number; electronic mail
         |                      | address.
         |                      | (b) "Holder of record" means any unit,
         |                      | officer, or contractor that acquires,
         |                      | stores, or transmits a protected
         |                      | identifier on behalf of the institution.
---------+----------------------+----------------------------------------
 12-103  | Duty of holders      | A holder of record shall (1) limit
         |                      | collection to the minimum necessary for
         |                      | a stated purpose; (2) designate in
         |                      | writing a Records Custodian; (3)
         |                      | maintain an access log; and (4) destroy
         |                      | records at the close of the retention
         |                      | period by shredding or equivalent
         |                      | means.
---------+----------------------+----------------------------------------
 12-104  | Penalty              | A holder of record who knowingly
         |                      | discloses a protected identifier in
         |                      | violation of this chapter is subject to
         |                      | a civil penalty of not more than $2,500
         |                      | per record disclosed and to discipline
         |                      | under the applicable personnel rule.
