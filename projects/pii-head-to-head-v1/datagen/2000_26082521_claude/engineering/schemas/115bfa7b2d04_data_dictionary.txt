DATA DICTIONARY EXCERPT — THIRD PARTY ELIGIBILITY WORK FILE
File TPELIG, VSAM KSDS, record length 512, copybook TPELIGC in PROD.COPYLIB
Prepared for the Systems Steering Committee, 22 SEP 2004

1. SCOPE. TPELIG is a staging file populated from carrier eligibility tapes received on a semi-monthly cycle and consumed by the online adjudication path. It is not a system of record; the authoritative content is the carrier's own file, and discrepancies are resolved in the carrier's favor without local correction. The file is nonetheless treated as protected health information in its entirety by direction of the Privacy Officer and carries the same handling class as the dispensing history.

2. KEY AND CONTROL FIELDS. The primary key is composed of CARR_ID_CD, PIC X(6), and MBR_ELIG_ID, PIC X(18), both required; the eligibility identifier is assigned by the carrier and its internal structure is not to be interpreted, decomposed, or used for matching. PERS_CD, PIC X(3), distinguishes covered persons within a contract and is required. GRP_NBR_CD, PIC X(15), is required. LOAD_CYCLE_NBR, PIC 9(5) COMP-3, and LOAD_TS, PIC X(26), are set by the load utility and are the only fields the operations group may inspect during a failed cycle.

3. DEMOGRAPHIC FIELDS. The following are present as received and are used only for match confirmation against the customer master: MBR_LAST_NAM PIC X(25), MBR_FRST_NAM PIC X(15), MBR_MID_INIT PIC X, MBR_BIRTH_DT PIC X(8), MBR_GENDER_CD PIC X, MBR_ZIP_CD PIC X(9). Carriers vary in their population of the birth date field; records arriving with it blank are written to the exception file TPELIGX and are worked by the third party billing unit, not by store staff. MBR_SSN_NBR, PIC X(9), appears in the copybook because three legacy carriers continue to transmit it in the layout position. It is overwritten with low values by the load utility before the file is closed, and any program referencing that field name in a READ path is to be flagged at code review.

4. RETENTION AND MOVEMENT. Generations are retained for four cycles on DASD and are then rolled to tape under the standard ninety-day media schedule; the tapes are inventoried by the Records Custodian and are not released to requesters outside third party billing. There is no downstream extract from TPELIG. Reporting requirements are satisfied from the adjudication history file, which carries no name fields and identifies the transaction by internal key only. Requests to join TPELIG to the marketing environment have been declined twice and are considered settled.
