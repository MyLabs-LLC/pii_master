FOOD AND NUTRITION SERVICES — DATA DICTIONARY EXCERPT
Database: NUTR_PROD (point of sale and eligibility)
Schema: nutr_elig
Prepared by the Office of Information Management
Cycle: annual review, 2021

  Table ELIG_APPLICATION
    Grain
      One row per household application per school year. Household composition is
      held in the child table ELIG_HH_MEMBER.
    Columns
      APP_ID                 int, NOT NULL, identity, primary key
      APP_YEAR               smallint, NOT NULL
      HH_ID                  int, NOT NULL, foreign key to the student information system household table
      APPLICANT_NAME_LAST    nvarchar(40), NOT NULL, restricted
      APPLICANT_NAME_FIRST   nvarchar(40), NOT NULL, restricted
      HH_SIZE_CNT            tinyint, NOT NULL
      HH_INCOME_AMT          decimal(9,2), NULL, restricted; null where the application is
                             approved by direct certification rather than income
      INCOME_FREQUENCY_CD    char(1), NULL, weekly, biweekly, monthly, annual
      CASE_NUMBER            varchar(16), NULL, assistance program case reference supplied
                             by the applicant; restricted, and excluded from every extract
                             defined below without exception
      DIRECT_CERT_FLG        bit, NOT NULL, default 0
      ELIG_STATUS_CD         char(1), NOT NULL, F free, R reduced, P paid, D denied
      DETERMINATION_DT       date, NOT NULL
      DETERMINED_BY_USER_ID  varchar(20), NOT NULL
      VERIFIED_FLG           bit, NOT NULL, default 0, set during the October verification sample
    Operational notes
      Provision status: three buildings operate under community eligibility for
      2021-22 and do not collect applications. Rows for those buildings are
      generated by the provision loader with DIRECT_CERT_FLG set to 1 and
      HH_INCOME_AMT left null.
      Carryover: prior-year eligibility remains in force for the first thirty
      operating days of the new year. The carryover job stamps APP_YEAR forward
      and clears VERIFIED_FLG.

  Table POS_ACCOUNT
    Grain
      One row per student meal account.
    Columns
      ACCT_ID          int, NOT NULL
      STU_ID_LOCAL     int, NOT NULL, unique
      BALANCE_AMT      decimal(7,2), NOT NULL, may be negative
      PIN_HASH         varbinary(64), NOT NULL, one-way hash, never exported
      LOW_BAL_ALERT_FLG bit, NOT NULL, default 1
      ACCT_STATUS_CD   char(1), NOT NULL

  Access restriction
    Eligibility status is visible to cafeteria managers as a serving indicator only.
    Underlying income, case reference, and applicant name columns are readable by the
    Nutrition Services Director and the Records Custodian. Building principals
    receive counts, not rows. Disclosure of individual eligibility status to
    instructional staff requires written authorization on file.

  Retention
    Applications and supporting determinations: three years after the end of the
    school year to which they apply, plus the current year, per federal program rules.
    Point of sale transaction detail: three years. Account balances are carried
    forward until graduation, then refunded or transferred to a sibling account.

  Downstream extracts
    Nightly load to the state child nutrition claiming system: building code,
    eligibility category, and meal counts. No name columns.
    Annual eligibility indicator to the assessment vendor: student identifier and
    ELIG_STATUS_CD collapsed to a two-value economic disadvantage flag.
    Quarterly file to the district data warehouse: collapsed flag only. The
    warehouse holds no application-level column from this schema.
