II. ACCESS RESTRICTION
Web tier connects under a service account with execute rights on stored procedures only. No table-level select is granted. Support staff use the read-only masked view VW_MBR_SUPPORT, which suppresses MBR_BIRTH_DATE, MBR_TIN_LAST4, MBR_PWD_HASH and MBR_PWD_SALT. Elevation is granted case by case by the Records Custodian and expires at end of shift.

III. RETENTION
Profiles inactive for thirty-six consecutive months are set to closed status by JB_MBR_DORMANT and the address, phone and date-of-birth columns are nulled. Closed profiles are deleted after a further twelve months unless LINKED_PTY_ID is populated, in which case the row is retained with the escrow file.

IV. DOWNSTREAM EXTRACTS
Weekly campaign extract, filtered on MBR_CONSENT_MKTG_FLAG = 1 and MBR_OPTOUT_DT is null. Carries name, mailing address and login email. Delivered to the vendor by managed file transfer. Suppression list is refreshed before each run; the Marketing Operations Manager certifies the count against the source query.
