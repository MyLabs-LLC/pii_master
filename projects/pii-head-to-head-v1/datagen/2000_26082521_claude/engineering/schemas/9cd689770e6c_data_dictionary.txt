DATA DICTIONARY EXCERPT — SUPPLEMENTARY SHEET
FORM DD-04S — TABLE CUSTDTA.MBR_CONSENT_AUD

SECTION 1 — IDENTIFICATION
1.1  Parent object: CUST_MBR_MSTR (see DD/CUST/0114).
1.2  Purpose: immutable audit of marketing and data-sharing consent changes.
1.3  Owner: the Records Custodian.

SECTION 2 — COLUMNS
2.1  AUD_SEQ_NO
       Type = NUMBER(14); Null = N; Note = insert-only; no update or delete grant issued to any application role.
2.2  MBR_ID
       Type = NUMBER(12); Null = N; Note = foreign key to parent; restricted by association.
2.3  CONSENT_TYPE_CD
       Type = CHAR(3); Null = N; Note = MKT / SMS / TPS / POST.
2.4  OLD_VAL_FLG
       Type = CHAR(1); Null = Y; Note = null on first capture.
2.5  NEW_VAL_FLG
       Type = CHAR(1); Null = N.
2.6  CHANGE_CHANNEL_CD
       Type = CHAR(2); Null = N; Note = WB / TE / DP / PO.
2.7  CHANGE_DTTM
       Type = DATE; Null = N; Note = server time, not client time.
2.8  CAPTURED_BY_USER_ID
       Type = VARCHAR2(12); Null = Y; Note = null where channel = WB.

SECTION 3 — CONTROLS
3.1  Retention: 6 years from CHANGE_DTTM, held independently of the parent purge at clause E.1 of DD/CUST/0114.
3.2  Access: read granted to RL_COMPLIANCE only. Customer service roles have no grant.
3.3  Extracts: none scheduled. Any release requires a signed request to the Records Custodian.
