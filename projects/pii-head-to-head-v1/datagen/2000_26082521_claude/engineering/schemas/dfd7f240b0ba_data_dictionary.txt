OPERATIONAL NOTES
Run window is Saturday 02:00-04:30 local. The job selects from MBR_TPA_V rather than
the base table; column additions to the base object do not propagate to the file
until the view and the fixed-length record layout are both amended.

Record layout is fixed at 412 bytes. Any width change requires a layout version bump
and a two-week parallel run with the receiving trading partner.

Transport is SFTP with PGP encryption at the file level. Keys rotate annually in
the third quarter. Failed transmissions retain the staged file in the outbound
directory for 72 hours, after which the cleanup script removes it.

Reconciliation counts are written to EXT_AUDIT_CTL. A variance above 2% in the row
count against the prior run halts the transmission and pages the on-call analyst.

Retention of the source rows is unaffected by this extract. Retention of the
transmitted file at the receiving party is governed by the business associate
agreement and is not managed here. Requests to add a suppressed column to this file
are directed to the Records Custodian and require privacy review before scheduling.
