DATA DICTIONARY — EXCERPT
SYSTEM: TitleWorks Settlement Platform (TWSP), production instance PRD01
PLATFORM: SQL Server 2008 R2, Enterprise
SCHEMA: dbo
OBJECT: PTY_MASTER — Party / Member Master
CLASSIFICATION: Restricted — Nonpublic Personal Information (GLBA Title V)
DICTIONARY REVISION: 4.2
EFFECTIVE: Q2 2016 release train
OWNER: Data Governance Office. Countersignature of the Records Custodian required for any change to Sections C, D or E.

SECTION A — OBJECT PROFILE
A.1 Object type: base table, clustered index on PTY_ID.
A.2 Source of record: escrow order intake queue; CIP capture at signing table; underwriter party feed.
A.3 Row population is per party per file; parties are not deduplicated across branches.
A.4 Object participates in nightly replication. See Section E.

SECTION C — ACCESS RESTRICTION
C.1 Base table select is denied to all interactive logins. Access is by view only.
C.2 The columns PTY_TIN, PTY_SSN_ENC, PTY_BIRTH_DATE and PTY_DL_NBR_ENC are excluded from VW_PTY_STD. Requests for the unmasked view require a signed access request approved by the Records Custodian and the Compliance Officer.
C.3 Ad hoc query access is not granted to branch personnel under any circumstance.

SECTION D — RETENTION
D.1 Party rows persist for the retention period of the parent escrow file.
D.2 PTY_DL_NBR_ENC and PTY_BIRTH_DATE are overwritten to null on the sixtieth day following disbursement, irrespective of file retention.
D.3 Legal hold suppresses all purge activity. Hold is applied at file level, not party level.

SECTION E — DOWNSTREAM EXTRACTS
E.1 Nightly extract to the marketing data mart. Restricted columns are not carried; the extract selects from VW_PTY_STD.
E.2 Monthly 1099-S submission file. Carries PTY_TIN. Encrypted at rest, transmitted by managed file transfer, purged from the staging area on receipt acknowledgement.
E.3 Underwriter remittance feed. Carries name and property reference only.
E.4 No extract to any non-production environment is authorised. Refresh of QA and DEV is performed from the scrambler output set.
