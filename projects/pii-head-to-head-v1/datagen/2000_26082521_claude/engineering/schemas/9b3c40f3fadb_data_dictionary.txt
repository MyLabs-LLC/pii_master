SECTION 3 — ACCESS RESTRICTION
  3.1  Class A columns are released only under an approved DP-207 access request
       countersigned by the program supervisor and the Records Custodian.
  3.2  Query profiles QRY01–QRY04 are constructed against V_MBR_CURR, which
       omits SSN_NBR, PHN_NBR_HOME and PHN_NBR_ALT.
  3.3  Ad hoc download to diskette or workstation drive is prohibited. Refer all
       requests to the Division for scheduled extract.

SECTION 4 — DOWNSTREAM EXTRACTS
  EXT-01  State immunization registry, weekly, fixed 240-byte record.
  EXT-02  WIC state agency reconciliation, monthly, tape transmittal.
  EXT-03  Epidemiology aggregate, quarterly. Class A columns suppressed;
          ZIP_CDE truncated to 5; DOB_DTE replaced by derived age band.
  EXT-04  Billing service bureau, semi-monthly. Class A columns limited to those
          enumerated on the executed data exchange agreement.

SECTION 5 — RETENTION
  5.1  Active rows retained on-line 24 months following ENRL_END_DTE.
  5.2  Purged rows written to archive file MBRHIST, retained seven (7) years
       per the state records retention schedule, series HD-4.
  5.3  Extract work files scratched at job end. No intermediate copies retained.
  5.4  Destruction of archive media requires DP-260 certificate of erasure.
