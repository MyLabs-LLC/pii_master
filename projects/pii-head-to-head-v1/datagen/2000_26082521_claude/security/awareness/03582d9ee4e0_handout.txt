CLOSING DEPARTMENT — DESK CARD
IDENTIFIER HANDLING. RETAIN AT WORKSTATION.

1. SHRED (crosscut console, not the wastebasket):
   drafts of settlement statements; escrow instruction working copies; identification photocopies; voided checks and wire request forms; payoff demands; fax confirmations; message slips bearing Social Security Number, Date of Birth, Loan Number, or Account Number.

2. NEVER SEND BY ELECTRONIC MAIL, INTERNAL OR EXTERNAL:
   Social Security Number / Taxpayer Identification Number / Date of Birth / Mother's Maiden Name / Driver's License Number / Bank Routing Number / Account Number / wire instructions / credit report content.

3. PRETEXT CALL INDICATORS — two or more, treat as hostile:
   manufactured deadline; no verifiable call-back number; cannot name their own supervising officer by title; asks you to confirm a partial identifier; asks who is out of the office; escalates when refused.

4. IF SUSPECTED:
   Give nothing. Do not confirm the file exists. Record caller's stated name, employer, and purpose. End the call; do not transfer. Memorandum to file same day.

5. ROUTE TO:
   Suspected pretext contact ................ Branch Manager
   Written incident memorandum .............. Information Security Coordinator
   File pulls, storage, destruction .......... Records Custodian
   Subpoenas and law enforcement ............. Underwriting Counsel
   Disclosure questions ...................... Compliance Officer

6. Clear desk at close of business. Lock all files. Log off terminals.
