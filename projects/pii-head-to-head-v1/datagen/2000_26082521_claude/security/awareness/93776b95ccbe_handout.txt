INTERNAL HANDOUT -- PROTECTION OF PERSONAL IDENTIFIERS
FORM PRV-104        ISSUED 2021        REVIEW CYCLE: ANNUAL
DISTRIBUTION: ALL BRANCH, TITLE AND ESCROW STAFF -- POST AT WORKSTATION

Every order we open gathers identifiers that a stranger can use to
impersonate a buyer, a seller, or a lender. The four tables below govern
how those identifiers are destroyed, transmitted, challenged, and
escalated. Follow them as written; branches do not set local variants.

TABLE 1 -- SHRED AND RETAIN MATRIX

+--------------------------+------------------------+----------+------------+
| DOCUMENT CLASS           | IDENTIFIER FIELDS      | RETAIN   | DISPOSAL   |
+==========================+========================+==========+============+
| Settlement worksheet     | Name, SSN, Loan No.    | Order+7y | Vendor bin |
| Photo ID copies          | DL No., DOB, Image     | Order+5y | Vendor bin |
| Wire instruction sheet   | Acct No., Routing No.  | Order+7y | Vendor bin |
| Payoff demand            | Loan No., SSN last 4   | Order+7y | Vendor bin |
| Commitment work copy     | Name, Property Addr.   | Closing  | Desk shred |
| Scratch notes, faxes     | Name, Phone No.        | Same day | Desk shred |
| Recorded instruments     | Name, Signature        | Order+7y | Vendor bin |
+--------------------------+------------------------+----------+------------+

Vendor bin means the locked console collected under contract. Desk shred
means the cross-cut unit at your own station, used before you leave it.

TABLE 2 -- WHAT NEVER TRAVELS BY EMAIL

+------------------------------------+--------------------------------------+
| FIELD OR DOCUMENT                  | APPROVED CHANNEL                     |
+====================================+======================================+
| Social Security Number             | Secure portal upload only            |
| Date of Birth                      | Secure portal upload only            |
| Driver's Licence Number            | Secure portal upload only            |
| Bank Account and Routing No.       | Portal, plus verbal callback         |
| Wire instructions, any form        | Portal, plus verbal callback         |
| Scanned identity documents         | Portal upload; no attachment         |
| Payoff statement                   | Portal link; no attachment           |
| Signed closing package             | Portal or bonded courier             |
| Any file holding the above         | Never leaves the portal              |
+------------------------------------+--------------------------------------+

Nothing in Table 2 moves in an email body, an attachment, a calendar
invitation, or a text message, inbound or outbound. A request from
outside the firm does not create an exception, and neither does a
request from inside it.

TABLE 3 -- RECOGNISING A PRETEXTING CALL

+--------------------------------------+------------------------------------+
| WHAT THE CALLER DOES                 | WHAT YOU DO                        |
+======================================+====================================+
| Opens with the file number           | Treat as public; verify anyway     |
| Says the closing is today            | Slow the call down                 |
| Refuses a callback to the number     | End the call; report it            |
| Asks you to confirm, not to state    | Never confirm an identifier        |
| Claims to be lender post-closing     | Call back via directory on file    |
| Asks for re-sent wire instructions   | Refer to Wire Verification Desk    |
| Reads a script; call-centre noise    | Note the time; report it           |
| Offers to update seller details      | Take no update by phone            |
+--------------------------------------+------------------------------------+

A pretexting caller works from a script and trades on courtesy. You are
not being rude when you take a name, take a role, and call back on the
number already recorded in the file. Two or more rows of Table 3 in the
same call is a report, not a judgement call.

TABLE 4 -- WHO TO TELL, BY ROLE

+--------------------------------------+------------------------------------+
| SITUATION                            | NOTIFY (ROLE TITLE)                |
+======================================+====================================+
| Suspected pretexting call            | Privacy Officer                    |
| Identifiers emailed in error         | Privacy Officer, then Manager      |
| Shred bin unlocked or overfull       | File Room Supervisor               |
| Paper with identifiers found loose   | Records Custodian                  |
| Request to change wire details       | Escrow Operations Manager          |
| Portal or workstation fault          | Information Security Lead          |
| Destruction certificate missing      | Compliance Officer                 |
| Anything you are unsure about        | Branch Manager                     |
+--------------------------------------+------------------------------------+

Report within one business hour of discovery. After hours, leave the
record with the duty Branch Manager and repeat it at open. No identifier
incident closes without a written note from the Privacy Officer.
