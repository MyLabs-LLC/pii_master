TRANSMISSION RESTRICTIONS AND INTERNAL CONTACTS
Escrow Operations Bulletin
Compliance Department, 2011

1.0 Never send by ordinary email
    1.1 The following fields, alone or in combination with a name: Social Security Number, Taxpayer Identification Number, Date of Birth, Driver's License Number, Bank Account Number, ABA Routing Number, Credit Card Number.
    1.2 Scanned identity documents of any kind.
    1.3 Wire instructions, whether in the body of a message or as an attachment.
    1.4 Full settlement statements to any party outside the transaction.
    1.5 Spreadsheets exported from the escrow system that retain the identifier columns, even where the sheet is filtered.

2.0 Approved alternatives
    2.1 The secure document portal, for anything in 1.0. Access is granted per file by the escrow officer of record.
    2.2 Hand delivery at the closing table.
    2.3 Courier in a sealed and logged envelope.
    2.4 Fax only to a confirmed machine in a locked room, with the recipient standing by. Confirm receipt by voice, then file the transmission report.

3.0 Practices that cause most incidents
    3.1 Autofill selecting the wrong recipient. Type the address, then read it back before sending.
    3.2 Reply-all on a lender thread that includes parties from another transaction.
    3.3 Forwarding a chain without reading what sits below the last message.
    3.4 Attaching the whole file when one page was requested.

4.0 If something goes out in error
    4.1 Do not attempt recall and then move on. Recall is not containment.
    4.2 Notify, in this order and within the same hour:
        Escrow Branch Manager
        Information Security Manager
        Compliance Officer
    4.3 Preserve the sent message and any bounce or read receipt.
    4.4 Expect a written account by end of day, describing what fields were exposed and to whom.

5.0 Who to reach, by role
    5.1 Records Custodian — file check-out, shred consoles, media check-in.
    5.2 Information Security Manager — devices, portal access, suspected exposure.
    5.3 Compliance Officer — release decisions, subpoenas, pretext reports.
    5.4 Escrow Branch Manager — first call for anything urgent during business hours.
    5.5 Extensions are on the internal directory posted at each workstation.
