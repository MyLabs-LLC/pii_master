release only after a return call to the University directory listing.

SECTION II -- CLAUSES
---------------------

1. Prohibition on electronic mail
   1.1 A field marked Prohibited in the E-MAIL column is never typed into a
       message, a subject line, a calendar entry, or an attachment, and is never
       pasted into a reply that quotes an earlier message.
   1.2 Staff do not remove the prohibition by abbreviating a field, by splitting
       it across two messages, or by placing it in a compressed archive.
   1.3 A message received from a student that itself contains a prohibited field
       is deleted from the mailbox and from the deleted-items folder after the
       transaction is completed on paper.

2. Destruction
   2.1 Any printout, working note, adding-machine tape, or screen print carrying
       a field from Section I is cross-cut shredded before the operator leaves
       the work area.
   2.2 Diskettes, CD-R discs, and tape cartridges are surrendered to the Records
       Custodian for physical destruction. Reformatting is not destruction.

3. Pretexting
   3.1 The following indicators, singly or together, require refusal: refusal to
       accept a return call; a request to fax to a number the caller supplies;
       a claim of employment, lending, or parental status offered as proof of
       right; pressure created by a stated deadline; and a request that staff
       read back a field the caller has partially recited.
   3.2 The refusal script is: the field requested is not released by telephone,
       and the Office will return the call using the published listing.
   3.3 Refusals are logged and forwarded to the Registrar Security Coordinator.

4. Interpretation
   4.1 Where this bulletin and a departmental practice conflict, this bulletin
       governs until amended in writing by the University Registrar.
