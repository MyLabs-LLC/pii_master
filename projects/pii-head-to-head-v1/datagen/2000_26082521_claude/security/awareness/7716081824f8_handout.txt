TO:      All Escrow Officers, Title Officers, Closing Coordinators, Receptionists, File Clerks
FROM:    Compliance Officer
SUBJECT: Safeguarding identifiers in the escrow file
ACTION:  Read, initial the branch log, retain in the branch procedures binder

Escrow files concentrate identifiers that are of value to persons outside this company. The following controls are mandatory.

SHRED
  • Anything bearing Social Security Number, Taxpayer Identification Number, Date of Birth, Driver's License Number, Account Number, Bank Routing Number, or Loan Number that is not the retained file copy.
  • Identification photocopies made for notarial verification once the acknowledgment is complete.
  • Superseded closing figures, prorations worksheets, and payoff demands.
  • Fax confirmations, message slips, envelopes, and mailing labels.
  • Crosscut console only. Do not carry shred material home or to another branch.

DO NOT SEND BY ELECTRONIC MAIL
  • Social Security Number, Taxpayer Identification Number, Date of Birth, Mother's Maiden Name.
  • Driver's License Number, Passport Number, State Identification Number.
  • Bank Routing Number, Account Number, wire instructions in any form.
  • Credit report content or lender underwriting conditions.
  • Attachments and subject lines are covered by this prohibition without exception. A request from a party to the transaction does not waive it.

PRETEXT CALLS
  A pretext caller impersonates someone entitled to the information. Indicators:
  • Invented urgency; a deadline that conveniently expires today.
  • Cannot identify their own supervising officer by title.
  • Asks you to read back or complete an identifier they claim to hold in part.
  • Requests the file itself rather than a specific figure.
  • Probes for absences, staffing, or which officer is least experienced.
  • Objects to a return call placed to the number already in the file.
  Response: disclose nothing, including whether the file exists; obtain the caller's stated name, employer, and purpose; end the call; do not transfer; memorandum the same day.

REPORT TO
  • Branch Manager — immediately, any suspected pretext contact or missing file.
  • Information Security Coordinator — written incident memorandum.
  • Records Custodian — file retrieval, off-site storage, media destruction.
  • Underwriting Counsel — subpoenas and law enforcement requests.
  • Human Resources Administrator — employee identifier questions.

No employee is authorised to release identifiers to an outside caller on their own judgment. When in doubt, refuse and refer.
