SUBJECT:  Field-Level Handling Matrix for Personal Identifiers
FILE:     CO-04-233

Customer master agreements executed this year impose handling obligations on identifier fields carried in our shipment, personnel, and driver qualification records. The matrix below states the required treatment of each field. Where a field appears on a form you originate, the treatment applies to every copy, including the file copy and the carbon.

FIELD LABEL / COLUMN NAME          RETAIN IN FILE   E-MAIL   DISPOSE BY
---------------------------------  ---------------  -------  -----------------
Social Security Number             Sealed folder    Never    Cross-cut shred
Date of Birth                      Sealed folder    Never    Cross-cut shred
Driver's License Number            Qualification    Never    Cross-cut shred
Medical Examiner Cert. Number      Qualification    Never    Cross-cut shred
Employee Number                    Open personnel   Never    Cross-cut shred
Bank Routing / Account Number      Payroll only     Never    Cross-cut shred
Payment Card Number / Exp. Date    Not retained     Never    Shred same day
Card Verification Value            Not retained     Never    Shred on receipt
Home Address / Home Telephone      Open personnel   Never    Cross-cut shred
Consignee Contact Name / Phone     Shipment file    Internal Cross-cut shred
Emergency Contact Name             Open personnel   Never    Cross-cut shred

"Never" in the E-MAIL column means the field is not to appear in the body, the subject line, or any attachment of a message leaving the corporate mail system, including messages to the customer's own personnel. Where a customer requests such data, the request is answered through the EDI gateway or the secure transfer host after the Compliance Officer confirms the contractual basis.

Card Verification Value is not to be written down, keyed into a note field, or retained after authorisation under any circumstance.

PRETEXT CALL INDICATORS

Billing and dispatch positions receive the majority of these approaches. The pattern is consistent:

   (a) The caller has the account or pro number but not the identifier they want.
   (b) The caller offers a partial identifier for you to "verify."
   (c) The caller cites a deadline, an audit, a claim hearing, or a failed transmission.
   (d) The caller asks for the record by fax, by mail to a residence, or read aloud.
   (e) The caller declines a call-back to a listed number, or supplies their own.

Any two of the above are sufficient grounds to end the exchange. Note the date, the shift, the stated employer, and the information sought.
