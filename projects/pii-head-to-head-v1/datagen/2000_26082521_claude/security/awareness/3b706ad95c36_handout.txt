IDENTIFIER HANDLING CHECKLIST — SHIFT USE
Form SEC-07 · Rev 4 · Retain at supervisor desk · Complete once per shift

SECTION A — CLEAR DESK AND CLEAR VEHICLE
[ ] Manifests, route sheets and PODs collected from all printers
[ ] Nothing bearing Consignee Name or Address left on cab dashboard, door pocket or bunk
[ ] Handheld terminals docked; screens locked
[ ] Fax tray emptied; misfeeds recovered from beneath the unit
[ ] Whiteboards wiped of Employee Reference and Payroll Number entries
[ ] Gatehouse visitor log closed and secured

SECTION B — SHREDDING
[ ] Cross-cut shredder in service; bin below half capacity
[ ] Locked console aperture clear; nothing stacked alongside
[ ] Shredded this shift: duplicate PODs, spoiled labels, cancelled manifests, agency booking sheets, recruitment photocopies, payroll enquiries, call notes
[ ] Destruction log annotated with Batch Reference and Consignment Count
[ ] Console key held by the Records Custodian or nominated deputy only

SECTION C — TRANSMISSION CONTROLS
Prohibited by email under all circumstances — confirm no instance this shift:
[ ] National Insurance Number
[ ] Passport Number / Driving Licence Number
[ ] Sort Code / Account Number / Card Number
[ ] Date of Birth against a Full Name
[ ] Personnel Master File extract, whole or partial
[ ] Scanned identity document
[ ] Removable media in use is encrypted and logged against a Media Serial Number
[ ] Client transfers made via approved secure facility, not attachment

SECTION D — PRETEXTING WATCH
Log any call showing two or more of the following:
[ ] Caller cannot state Depot Cost Centre Code or Purchase Order Reference
[ ] Caller asks you to confirm rather than supply
[ ] Urgency, cut-off deadline, or named senior manager who is unreachable
[ ] Request for an internal transfer or a colleague's extension
[ ] Callback number offered by the caller
[ ] Repeat call from a second party supporting the first
Action taken: [ ] Nothing disclosed  [ ] Call terminated  [ ] Details recorded  [ ] Escalated

SECTION E — ESCALATION ROUTING

  Event                                  | Route to
  ---------------------------------------|----------------------------------
  Suspected pretexting call              | Depot Security Officer
  Paperwork lost, mislaid or blown loose | Records Custodian
  Email or fax sent to wrong recipient   | Data Protection Coordinator
  Unencrypted media found on site        | IT Service Desk Lead
  Console forced, jammed or overfilled   | Facilities Duty Manager
  Agency worker unbriefed on this form   | Transport Shift Supervisor
  Repeat or unresolved incident          | Compliance Manager

SECTION F — CLOSE OF SHIFT
[ ] Sections A to E completed
[ ] Exceptions recorded in the Shift Incident Register
[ ] Form countersigned by the outgoing Transport Shift Supervisor
[ ] Form filed; not left on the desk surface

Late reporting reduces the options available to the Company. Report within the shift in which the event occurs.
