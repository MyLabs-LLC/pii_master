RECOGNISING A PRETEXTING CALL

Pretexting is the use of a fabricated role and an urgent scenario
to obtain identifiers held on file. Calls follow a narrow set of
patterns, listed below.

CALLER CLAIM                    OBSERVED PATTERN            REQUIRED ACTION
------------------------------  --------------------------  --------------------
Payroll audit verification      Refuses ticket reference    Terminate; log PR-07
Benefits carrier update         Caller ID withheld          Refer: Privacy Off.
Urgent placement start today    Time pressure applied       Do not confirm; log
Password reset assistance       Asks staff to read back     Refer: Info Sec Lead
Court or agency records req.    No written request on file  Refer: Records Cust.
Client site badge office        Requests delivery rerouted  Terminate; log PR-07

THREE RULES

  1. Identity is established outbound, never inbound. Call the
     number held on the account record.
  2. Never confirm, partially confirm, or deny a Social Security
     Number, Date of Birth, or account number to a caller.
  3. Log every terminated call the same day. A pattern across
     branches is only visible if each call is recorded.

Ending a legitimate call causes a short delay. Completing an
illegitimate one causes a reportable disclosure.
