PRETEXTING SCREENING CHECKLIST — TELEPHONE AND WALK-UP
Complete mentally on every call requesting patient-specific information.
Acknowledgement required at quarterly training. Retain unmarked copy at station.

STEP 1 — IDENTIFY THE CALLER CATEGORY
[ ] Patient or authorised representative on file
[ ] Prescriber or prescriber's agent, verifiable by DEA or NPI on record
[ ] Transferring pharmacy, verifiable by NABP number
[ ] Payer or PBM representative
[ ] Internal, claiming corporate, IT, audit, or executive authority
[ ] None of the above — TERMINATE

STEP 2 — RED FLAG SCORING (ANY ONE BOX = TERMINATE AND REPORT)
[ ] Caller declines a return call to the number held on record
[ ] Caller supplies a partial identifier and requests confirmation of the balance
[ ] Caller requests more than one patient record on a single call
[ ] Caller asserts a system outage, audit deadline, or disciplinary consequence
[ ] Caller requests Social Security Number, full card data, or login credentials
[ ] Caller requests that data be emailed, texted, or photographed
[ ] Caller's stated role does not match the information requested
[ ] Background audio suggests a call centre while caller claims to be a prescriber's office
[ ] Caller becomes hostile, flattering, or personal when questioned

STEP 3 — PERMITTED VERIFICATION
Confirm, do not disclose. Ask the caller to state:
[ ] Full Name, spelled
[ ] Date of Birth
[ ] Address on file
[ ] Prescription Number in question
Compare against the record. If any element is offered incorrectly and the caller attempts a second guess, terminate.

STEP 4 — DISPOSITION
[ ] Request satisfied under verified category
[ ] Call returned to number on record; request satisfied
[ ] Call terminated; incident slip completed
[ ] Data disclosed before red flag recognised — REPORT IMMEDIATELY

REPORTING SEQUENCE
1. Pharmacy Manager on Duty — same call, before the next transaction
2. Store Privacy Coordinator — same shift
3. District Loss Prevention Manager — where an in-person approach or badge display occurred
4. Regional Compliance Officer — within 24 hours, via the incident form on the intranet

No staff member is subject to correction for terminating a call under this checklist. Failure to report a suspected pretext is a separate matter.
