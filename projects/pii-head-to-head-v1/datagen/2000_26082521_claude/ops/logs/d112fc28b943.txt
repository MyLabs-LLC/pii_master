FIELD MAPPING RULE SET — SOURCE CMASTR.VSAM → TARGET CDW.STG_CONSIGNEE

1.0 SCOPE

1.1 This rule set governs the extraction of consignee and delivery-contact attributes from the legacy VSAM cluster CMASTR and their load into the staging table CDW.STG_CONSIGNEE on the Informix instance CDWP01.

1.2 Attributes not enumerated in clause 3.0 are excluded from extract and are not written to the target. No default substitution is performed for excluded attributes.

1.3 Copybook of record is CPYCMST.CPY, level 03 group CONSIGNEE-CONTACT-GRP.

2.0 EXECUTION WINDOW

2.1 The extract executes under job stream CDW1140 nightly at 23:15 CST. Late-arriving source files are held until the following window; partial loads are not permitted.

2.2 The Y2K-remediated date routine DTCONV4 is invoked for all mapped date fields. Two-digit century pivot is fixed at 40.

4.0 TRANSFORMATION RULES

4.1 R-01 (NAME NORMALISE). Trim trailing low-values, fold to upper case, collapse internal spaces to single. Output written to target only where the calling job supplies clearance code NAM-FULL. Absent that code the target column receives the surrogate produced by TOKGEN v2.1 and the cleartext is discarded from the work area before commit.

4.2 R-02 (ADDRESS NORMALISE). Street-line components are parsed by ADRPARS into unit, thoroughfare and locality subfields. Only locality and thoroughfare-type are retained on the target; the remainder is suppressed under clause 5.2.

4.3 R-03 (POSTAL TRUNCATE). Retain leading three characters. Remaining positions receive fill character '*'.

4.4 R-04 (CONTACT SUPPRESS). Column is created on the target with NULL and is not populated by this job stream. Downstream requests for these columns are routed to the Records Custodian.

4.5 R-05 (LICENCE TOKENISE). Surrogate issued by TOKGEN v2.1, format TKN-L-nnnnnnnn. Reversal table resides on RSTORE01 and is not accessible to the ETL user ID CDWETL.

4.6 R-06 (DATE GENERALISE). Retain century and year of birth only; month and day positions receive fill character '*'. Target column type is CHR(8), not DATE.

5.0 RESTRICTIONS

5.1 The ETL user ID CDWETL holds INSERT and SELECT only on CDW.STG_CONSIGNEE. No UPDATE or DELETE grant is issued.

5.2 Suppressed subfields are not written to the SORTWK datasets. The exit routine SUPPWIPE clears the work area at end of step.

5.3 Spool output from CDW1140 is directed to class H (hold) and purged after 72 hours. Field values are not permitted in spool.

5.4 Any amendment to clauses 3.0 or 4.0 requires re-issue of this document at the next revision number and countersignature by the Divisional Controller.
