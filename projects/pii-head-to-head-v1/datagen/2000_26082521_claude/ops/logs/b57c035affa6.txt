; ------------------------------------------------------------------
; ENFORCEMENT
; ------------------------------------------------------------------
; Any column arriving in a staging table without a matching profile
; assignment is written to the quarantine schema and the load step is
; marked FAILED. The unmatched column name is recorded; its contents
; are not. Quarantine tables are purged on a fourteen-day cycle.
;
; Deterministic tokenization is required so that joins across the
; enrollment, billing and housing extracts continue to resolve on the
; token rather than on the underlying value. Vault rotation is annual
; and breaks prior-year joins by design; extracts spanning a rotation
; boundary must be regenerated in full rather than appended.
;
; Reversal of a token requires a service ticket referencing the
; business purpose, the requesting office, and the approval of the
; Data Steward. Reversal events are written to VLT_REG_01_AUDIT with
; the requesting account, the ticket number and the count of tokens
; resolved. Bulk reversal in excess of 50 tokens is refused by the
; vault service and must be handled as a scheduled extract.
;
; Profiles MP-01, MP-08, MP-09, MP-11, MP-12, MP-14, MP-15 and MP-18
; are locked. The configuration loader rejects the entire file if the
; method value for any locked profile is altered.
; ------------------------------------------------------------------
