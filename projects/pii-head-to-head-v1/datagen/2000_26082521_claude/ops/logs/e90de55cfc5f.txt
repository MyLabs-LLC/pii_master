  III. TOKENISED MOVES
     A. CDR-MED-REC-NBR ........... -> MEDICAL_RECORD_NBR
        1. Vault class B, stable surrogate, format preserved.
        2. Vault miss raises E-443; row held, not defaulted.
     B. CDR-CASE-ID ............... -> CASE_REGISTRY_ID
        1. Surrogate is the sole join key downstream.
        2. Natural key is not carried to any target column.
     C. CDR-WIC-NBR ............... -> WIC_PARTICIPANT_NBR
        1. Populated only where PROGRAM_ENROLLMENT_CD indicates WIC.
        2. Otherwise target written as <NULL>; absence is not an error.

  IV. DERIVED AND GENERALISED COLUMNS
     A. AGE_AT_REPORT_YRS
        1. Derived from DATE_OF_BIRTH and REPORT_DATE at extract time.
        2. Source DATE_OF_BIRTH is generalised to CCYY0000 before write.
        3. Values above 89 collapse to a single top band.
     B. RESIDENCE_ZIP3
        1. First three positions of RESIDENCE_ZIP retained.
        2. Remaining positions written as fill character.
     C. GEOG_UNIT_CD
        1. Assigned from CENSUS_TRACT_CD via domain table DOM-GEO-14.
        2. Unmatched tract yields E-302 and a held row.
