XFORM CODE LEGEND
-----------------
 PASSTHRU     Value copied without alteration. Permitted for non-PHI only.
 TOKEN_SHA1   Value replaced by digest token from TOKEN_VAULT.RXMBR. Source
              value is never written to staging, spool, or session log.
 TOKEN_HMAC   Keyed token, key ref RXKEY_2004Q1. Rotation due 2004-07-01.
 GEN_YEAR     Retains 4-digit year component only. Day and month discarded.
 TRUNC_3      Retains leading 3 positions. Remaining positions space filled.
 SUPPRESS     Column created in target, populated with masked placeholder
              constant '****'. Column is not indexed.
 DROP_COLUMN  Column excluded from target DDL. Any inbound occurrence is
              counted in REJ_DROP and discarded before the staging write.
