# This configuration is promulgated pursuant to the Corporate Information
# Handling Standard (CIHS-002) and to such obligations as are imposed upon the

# Individually Identifiable Health Information, and is intended to give
# operational effect to the minimum necessary principle by ensuring that no
# element of protected health information, and no element of individually
# identifiable financial information, is materialized in cleartext within any
# non-production schema, extract file, spool area, reject queue, or operator
# console listing under the control of the Data Warehouse Services group.
#
# Each stanza below binds a source column, identified by its physical name as it
# appears in the governing copybook or table definition, to exactly one masking
# transform. Where the transform is designated TOKENIZE, the value shall be
# replaced by a referentially consistent surrogate drawn from the token vault,
# such surrogate to be stable across all jobs sharing a vault domain so that
# joins survive; where the transform is designated LITERAL, the value shall be
# overwritten in its entirety by the stated placeholder; where the transform is
# designated SUPPRESS, the column shall be propagated as NULL and the target
# constraint relaxed accordingly. No transform may be disabled, overridden, or
# bypassed by session parameter, and any attempt to do so shall cause the
# workflow to abort with return code 88 and to raise an entry in the privacy
# exception register. Deviations require the countersignature of the Records
# Custodian and of the Director of Pharmacy Systems, recorded in change ticket
# form prior to promotion.
