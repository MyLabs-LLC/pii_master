RESTRICTED INFORMATION — POCKET REFERENCE
Records Management Unit / Revised August 2004

  1.0  BEFORE YOU RELEASE, ASK
       1.1  Who is asking?
       1.2  Do they have a legitimate educational interest?
       1.3  Is the opt-out flag set?
       1.4  Has the disclosure been logged?

  2.0  NEVER RELEASE WITHOUT WRITTEN CONSENT
       2.1  Social Security Number
       2.2  Evaluation Report / IEP Goals / Eligibility Category
       2.3  Medication Administration Log / Immunization Status
       2.4  Free/Reduced Meal Eligibility Status
       2.5  Disciplinary Referral Code
       2.6  Employee Home Address / Home Telephone Number / Date of Birth

  3.0  MAY RELEASE — DIRECTORY INFORMATION ONLY
       3.1  Student Name
       3.2  Participation in Officially Recognized Activities
       3.3  Diplomas and Awards Received
       3.4  Check the opt-out flag first. Every time.

  4.0  IF YOU MISHANDLE
       4.1  Report to the Building Principal same day.
       4.2  Complete the Incident of Unauthorized Disclosure form.
       4.3  Discipline ranges from written reprimand to termination.
       4.4  Concealment is a separate offense.

  5.0  TWO-MINUTE CHECK
       5.1  A caller states they are a relative and requests a schedule. Release?
       5.2  A staff member leaves a printed class list with meal eligibility on the copier. Report?
       5.3  A teacher e-mails a grade report to a personal account to finish at home. Permitted?

  6.0  WHEN IN DOUBT, DO NOT RELEASE. CALL THE RECORDS CUSTODIAN.
