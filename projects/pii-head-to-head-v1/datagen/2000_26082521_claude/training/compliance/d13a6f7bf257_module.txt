SLIDE 02 : WHAT IS RESTRICTED
....................................................................
ON SCREEN:
  CLASS A — IDENTIFIERS
    Patient Name ... Medical Record Number ... Account Number
    Social Security Number ... Date of Birth ... Health Plan ID
  CLASS B — CONTACT
    Street Address ... Telephone ... Email ... Employer Name
  CLASS C — FINANCIAL INSTRUMENT
    Card Account Number ... Expiration ... CVV ... Routing Number
  CLASS D — SENSITIVE CLINICAL
    Diagnosis Narrative ... Reproductive Care Flag ... HIV Status
    Behavioral Health Flag ... Substance Use Treatment Flag
SAY: Class C is never stored in a free-text note under any condition.
Class D requires separate written authorization before release.

SLIDE 03 : PERMITTED USE TEST
....................................................................
ON SCREEN:
  TEST 1 ....... IS THERE A DOCUMENTED BUSINESS NEED
  TEST 2 ....... IS THE DISCLOSURE MINIMUM NECESSARY
  TEST 3 ....... IS THE RECIPIENT VERIFIED AND AUTHORIZED
  TEST 4 ....... IS THE CHANNEL APPROVED AND ENCRYPTED
SAY: All four must pass. One failure stops the disclosure.
