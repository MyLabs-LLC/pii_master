SECTION 1. WHAT IS RESTRICTED

A record is restricted when it carries any one of the field labels shown below.
The class is set by the label present, not by the department holding the file.

+-------+--------------------------+----------------------------------------------+
| CLASS | RECORD CATEGORY          | FIELD LABELS PRESENT IN THE RECORD           |
+-------+--------------------------+----------------------------------------------+
| R-1   | Employee Personnel and   | Name; Social Security Number; Date of Birth; |
|       | Payroll Records          | Home Address; Home Telephone; Direct Deposit |
|       |                          | Account Number; Marital Status; Dependents   |
| R-2   | DOT Drug and Alcohol     | Donor Name; Specimen Identification Number;  |
|       | Testing Files (Part 40)  | Collector Signature; MRO Verified Result;    |
|       |                          | Return-to-Duty Date; Follow-Up Test Schedule |
| R-3   | Paratransit Eligibility  | Applicant Name; Date of Birth; Diagnosis;    |
|       | and Medical Files        | Verifying Physician; Mobility Aid; Trip      |
|       |                          | Purpose; Certification Expiration Date       |
| R-4   | Fare Media and Customer  | Cardholder Name; Card Serial Number; Credit  |
|       | Accounts                 | Card Number; Expiration Date; Billing        |
|       |                          | Address; Autoload History; Refund Amount     |
| R-5   | Sensitive Security       | Facility Name; Vulnerability Assessment;     |
|       | Information (Part 1520)  | Camera Coverage Map; Key Control Roster;     |
|       |                          | Alarm Code Assignment; Patrol Schedule       |
| R-6   | Surveillance Video and   | Recording Location; Date and Time Stamp;     |
|       | Incident Reports         | Operator Badge Number; Complainant Name;     |
|       |                          | Witness Statement; Police Case Number        |
| P-0   | Public Information       | Route Schedule; Fare Table; Board Agenda;    |
|       |                          | Adopted Budget; Ridership Summary Totals     |
+-------+--------------------------+----------------------------------------------+

SECTION 2. HOW EACH CLASS IS HANDLED

+-------+------------------------------------------------+------------------------+
| CLASS | MINIMUM HANDLING REQUIREMENT                   | RELEASE APPROVED BY    |
+-------+------------------------------------------------+------------------------+
| R-1   | Locked file room; need to know; shred at purge | HR Director            |
| R-2   | Separate locked file; no personnel file entry  | Medical Review Officer |
| R-3   | Medical file kept apart from personnel file    | ADA Coordinator        |
| R-4   | Mask all but last four digits on any printout  | Revenue Manager        |
| R-5   | Marked cover sheet; no e-mail; hand delivery   | Security Manager       |
| R-6   | Log every viewing; retain thirty days maximum  | Risk Manager           |
| P-0   | Release on request; no approval memorandum     | None Required          |
+-------+------------------------------------------------+------------------------+
