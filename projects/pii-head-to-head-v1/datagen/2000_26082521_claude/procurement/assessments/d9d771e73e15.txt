MEMORANDUM

TO:      Supplier Records Custodians
FROM:    Office of Information Security, Vendor Risk Management
SUBJECT: Preparing Evidence Attachments for the Security Assessment Questionnaire
DATE:    Second Quarter 2016

Several return packages received this quarter were rejected on intake. This memo explains what is expected so that resubmission is not necessary.

Attachments must be indexed. Each item in the questionnaire marked Evidence Required in the right-hand column expects one attachment. Number the attachments sequentially and write the number in the Evidence column beside the item. An attachment supporting more than one item may be referenced more than once.

Attachments must not contain populated personal information fields. Where the requested evidence is an operational record — a destruction certificate, a transfer log, an access review extract — supply the form with the field labels and column headings intact and the value positions empty. Column names such as Record Identifier, Media Type, Date of Destruction, and Custodian Role are the substance of the evidence. The values are not required and will cause the package to be returned.

Attachments must be legible and dated. Undated procedures cannot be scored. A procedure with a version number and an effective date is preferred to a printed page with no provenance.

Attachments must correspond to the environment in scope. Evidence drawn from a corporate standard that does not apply to the environment holding our data will be scored as absent.

Do not substitute narrative for evidence. A description of a key rotation practice in the response box does not satisfy the evidence requirement for item 2.2; the key management procedure itself is required.

Return packages go through the supplier portal only. Attachments sent by other means are not accepted and are deleted on receipt.

Where an item genuinely does not apply, write "not applicable" in the response box with a one-line reason. Leave no box empty. Blank boxes are treated as incomplete regardless of applicability.
