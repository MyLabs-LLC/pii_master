PART II — CLAUSES

Clause 1. Storage of Personal Information

    1.1  The Vendor shall describe every repository in which personal information
         is held, including production databases, reporting environments,
         development or test environments, and offline archives.

         │                                                                    │
         │                                                                    │
         │                                                                    │
         Evidence required: data flow diagram and asset inventory extract.

    1.2  The Vendor shall state whether personal information is replicated to
         any location outside the country of origin, and if so, the legal basis
         relied upon.

         │                                                                    │
         │                                                                    │
         Evidence required: none.

    1.3  The Vendor shall state whether personal information is present in
         non-production environments and, if so, whether it is masked.

         │                                                                    │
         │                                                                    │
         Evidence required: masking standard or procedure document.

Clause 2. Encryption Controls

    2.1  The Vendor shall specify the encryption standard applied to data at
         rest, including algorithm, mode of operation, and key length.

         │                                                                    │
         │                                                                    │
         Evidence required: cryptographic standard, current version.

    2.2  The Vendor shall confirm that cryptographic keys are held separately
         from the data they protect and identify the role title responsible for
         custody of each key.

         │                                                                    │
         │                                                                    │
         Evidence required: key management procedure.

    2.3  The Vendor shall confirm that no personal information is stored on
         removable media unless that media is encrypted and inventoried.

         │                                                                    │
         │                                                                    │
         Evidence required: removable media register, header page only.

Clause 3. Transmission

    3.1  The Vendor shall list every channel by which personal information
         enters or leaves its environment, including scheduled file transfer,
         web service, courier of physical media, and facsimile.

         │                                                                    │
         │                                                                    │
         │                                                                    │
         Evidence required: interface catalogue.

    3.2  The Vendor shall confirm that transport encryption is enforced and
         that fallback to unencrypted transport is disabled.

         │                                                                    │
         │                                                                    │
         Evidence required: configuration extract.

Clause 4. Retention and Secure Disposal

    4.1  The Vendor shall state the retention schedule applied to personal
         information and the trigger event that starts the retention clock.

         │                                                                    │
         │                                                                    │
         Evidence required: retention schedule.

    4.2  The Vendor shall describe the disposal method for each media type and
         name the role title of the Records Custodian accountable for disposal.

         │                                                                    │
         │                                                                    │
         Evidence required: disposal procedure and specimen certificate with
         all identifying entries left blank.

    4.3  The Vendor shall confirm the process for returning or destroying
         personal information at contract termination, and the period within
         which this is completed.

         │                                                                    │
         │                                                                    │
         Evidence required: none.
